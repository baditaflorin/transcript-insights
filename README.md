# Transcript Insights

This is a Next.js application built with Firebase Studio that allows you to analyze conversation transcripts to extract valuable insights, action items, perspectives, and more using powerful AI models.

## How to Use

1.  **Configure AI**:
    *   Select your desired AI Provider (Google AI or OpenAI).
    *   Enter your corresponding API key in the "API Key" field. This is required.

2.  **Provide a Transcript**:
    *   **Paste Text**: Copy your full transcript and paste it directly into the text area.
    *   **Upload File**: Click "Upload File" to select a text-based file (like `.txt` or `.md`) from your computer.

3.  **Select Analyses**:
    *   Under "Select Analyses", check the boxes for the types of insights you want to generate. You can select any combination.

4.  **Analyze**:
    *   Click the "Analyze Transcript" button to start the process. The analysis will take a few moments.

5.  **View and Download Results**:
    *   The results will appear on the right side, organized into tabs for each analysis type you selected.
    *   You can download each individual analysis as a Markdown file using the download icon on each card.
    *   You can also download all generated analyses together in a single file by clicking the "Download All" button. The filename will be automatically generated based on the transcript's content.
