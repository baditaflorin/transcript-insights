# **App Name**: Transcript Insights

## Core Features:

- Transcript Input: Accept user input via file upload or pasted text transcript.
- Perspective Analysis: Generate a file explaining the conversation from each speaker's point of view, identifying their goals and contributions using an AI tool.
- Action Item Extraction: Create a checklist of action items for each speaker, based on the transcript, clearly assigning responsibility with an AI tool.
- Open Question Identification: Identify any unanswered questions or topics requiring follow-up from the conversation, phrasing them as questions using an AI tool.
- File Generation & Download: Generate and allow the user to download the perspective analysis, action item checklist, and open questions as separate text files.

## Style Guidelines:

- Primary color: Light blue (#72BCD4) to suggest clear communication and objectivity.
- Background color: Very light blue (#F0F8FA), almost white, for a clean and readable interface.
- Accent color: Muted orange (#A1887F) to draw attention to key actionable items and calls to action.
- Font: 'Inter', a sans-serif font, will be used throughout for its clean and professional look.
- Clear, linear layout, dividing the input area from the processing/output area.
